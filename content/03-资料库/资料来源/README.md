# Sources

Provenance layer for evidence used by Knowledge OS.

A source can be a chat episode, web page, PDF, report, screenshot, transcript or user note.

Source notes should preserve:

- what the source is,
- when it was captured,
- why it matters,
- what it supports,
- its limitations,
- which knowledge items it may affect.

Do not treat source notes as canonical truth. Conflicting sources can coexist until the Curator resolves or scopes the disagreement.
