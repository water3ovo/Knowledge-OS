# Learning Episodes

Process-memory layer for how understanding evolved.

Use Learning Episodes to preserve:

- questions,
- initial mental models,
- corrections,
- personal insights,
- unresolved questions,
- the final Knowledge Delta.

Learning files are not canonical reference pages. They explain *how the learner's understanding changed* and help future sessions resume from the right point.

Prefer one episode per meaningful topic/session rather than one file per chat message.
