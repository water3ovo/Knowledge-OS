## 最近更新的知识

```dataview
TABLE WITHOUT ID
  file.link AS "知识",
  choice(domain = "strategy", "战略与经营", choice(domain = "growth", "增长", choice(domain = "ai", "AI 产品", choice(domain = "data", "数据分析", choice(domain = "platform", "平台机制", domain))))) AS "领域",
  dateformat(file.mtime, "MM-dd HH:mm") AS "更新"
FROM "01-知识库"
WHERE type != "map"
SORT file.mtime DESC
LIMIT 6
```

## 最近学习

```dataview
TABLE WITHOUT ID
```

## 待消化资料

```dataview
TABLE WITHOUT ID
```

## 开放问题

```dataview
TABLE WITHOUT ID

  open_questions AS "开放问题"

```
