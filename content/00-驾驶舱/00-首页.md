## 这套系统如何自己生长

**ChatGPT 学习 / 浏览资料 → 形成 Learning Episode 与 Knowledge Delta → 更新 GitHub Markdown → Obsidian Git 自动同步 → 知识地图、Backlinks、Graph 与索引继续生长。**

> `.base` 文件负责索引和管理，不再承担主要阅读体验。日常使用优先从本页、知识地图、领域导航页和白板进入。
