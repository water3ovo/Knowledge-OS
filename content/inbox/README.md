# Inbox

Temporary capture queue for material that has entered the system but has not yet been curated.

Examples:
- a URL dropped during learning
- a PDF/report awaiting review
- a screenshot or rough note
- an external highlight batch

Rules:

1. Inbox is not canonical knowledge.
2. Items should eventually become Source records, Learning Episodes, Knowledge updates, or be discarded.
3. Do not let Inbox become a permanent archive.
4. Prefer provenance over premature summarization.
