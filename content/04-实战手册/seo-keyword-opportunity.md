## WHAT

从需求、意图、竞争和商业价值四个维度找到值得创建页面的关键词机会，而不是只追求搜索量。

## HOW

1. 从产品场景、竞品页面、Google Suggest、Keyword Planner 等建立 Seed Keywords。
2. 扩展相关词并按 Topic Cluster 去重归类。
3. 判断 Search Intent：信息、商业调研、交易或导航。
4. 查看真实 SERP，确认 Google 当前偏好的页面类型和竞争者。
5. 综合搜索量、难度、商业意图、产品相关性和现有站点权威性排序。
6. 决定 Landing Page / Comparison / Use Case / Blog / Programmatic Page 等页面形态。
7. 上线后用 Search Console 复盘 Impression → CTR → Conversion，而不是只看排名。

## OUTPUT

- Keyword Opportunity List
- Topic Cluster
- 页面优先级
- Content Brief
- 上线后的监测指标
