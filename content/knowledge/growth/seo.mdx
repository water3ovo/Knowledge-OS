## WHAT

SEO（Search Engine Optimization）是通过提升网页可抓取性、内容相关性、用户体验和站点可信度，让用户在 Google 等搜索引擎中更容易自然发现网站的增长方法。

## WHY

SEO 不是一次性买量，而是在真实搜索需求上建立可持续的自然获客入口。对于 AI 产品出海，它还能帮助团队理解用户搜索意图、需求规模和竞争格局。

## WHEN

- 用户会主动搜索某类问题 / 产品时
- 产品需要降低长期获客成本时
- 有大量可沉淀内容、工具页或模板页时
- 需要通过搜索验证市场需求时

## HOW

1. 找到用户真实搜索的 Keyword / Topic。
2. 判断 Search Intent：信息、比较、购买、导航等。
3. 研究 SERP 与竞争页面，判断用户期待什么答案。
4. 创建满足意图的页面和内容。
5. 做 Technical SEO，确保搜索引擎能抓取、索引和理解页面。
6. 通过内部链接、品牌与 Backlink 建立权威性。
7. 用 Search Console 持续观察 Impression、Click、Query 与排名变化。

## DATA

- Keyword / Topic Demand
- SERP
- Search Console Query
- Impression / Click / CTR
- Ranking
- Backlink
- Landing Page Conversion

## TOOL

- Google Search Console
- Google Trends
- Google Keyword Planner
- Semrush
- Ahrefs
- Bing Webmaster Tools

## OUTPUT

- Keyword / Topic Map
- Content / Landing Page Plan
- Search Traffic
- SEO Opportunity List
- Search Performance Dashboard

## PITFALLS

- 为搜索引擎堆关键词，而不是解决用户问题
- 只看 Search Volume，不看 Search Intent 和商业价值
- 把流量增长等同于业务增长，不看最终转化
- 忽略技术抓取与索引问题
